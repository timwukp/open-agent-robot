# R1.1 — 把 /memory/profile 接進提示,並且對「回合早於卡片」出一個 finding。
#
# R1 六個接線 PR 的第一個。agent_node 訂閱 latched 的 /memory/profile、把卡片
# 傳進 context.assemble(card=…)、卡片到達時**重組**提示。graph_gaps.tsv 少一列,
# dormant_seams.tsv 少兩列。
#
# **誠實邊界,只講一次而且是字面意思:結構斷言證明線被宣告了,不證明訊息真的流過去。**
# 兩個節點都 import rclpy,而 test-design.md §6.1 要求這套測試在沒有 ROS 的筆電上跑,
# 所以每一條斷言都是對節點的**原始碼**做的。證明卡片真的到得了是 L4,而 L4 需要 /32。
#
# 計劃 §4 的 R1.1 那一列有四件事,三件的結果跟計劃不同:
#   1. assemble 在 __init__ 只跑一次而卡片是異步的 —— 計劃自己說這是設計決定不是接線。
#      解法:assemble 是純函式,所以卡片到達時重組提示,而早於卡片的那個回合留下
#      一筆稽核紀錄。一個第一回合安靜地忘記你、第二回合又記得你的機器人,比一個
#      從來不記得的更糟,因為它的日誌分辨不出這兩件事。
#   2. **guard.audit_record 兩個方向都接不了那筆紀錄。** context.audit_payload 的
#      docstring 指名它是消費者;store.check_audit 兩邊都拒絕:留著 guard.audit_record
#      蓋的 kind="audit",blocks/chars/findings 就是未宣告欄位;改成 "chat",
#      action/decision/reason 就是。那句錯的話被跟著走過三個檔案(docstring、
#      引用它的 AUDIT_FIELDS 註解、以及 dormant_seams.tsv 說它是這個接縫呼叫者的那一列)。
#      現在它是兩條 pytest.raises,而不是第四句話 —— 一句被更正的 docstring 仍然是 docstring。
#   3. **unlock_for_s5() 從來就不是 R1.1 的,而 R1.1 是那個必須把這件事說出來的回合。**
#      那個鎖寫下來的理由是 provenance:一個語義事實必須指名它從哪些 episode 來,
#      這樣刪掉一個 episode 才會刪掉它產生的東西。episode 要到 R1.3 才有,所以現在
#      寫下的卡片會裝著任何刪除都到不了的事實。R1.1 接的是**讀**的那一半,不能轉那把鑰匙。
#
# 稽核紀錄走**一跳**而不是第二個寫入者:agent_node 手上沒有 Store,它把紀錄發到
# /memory/audit,memory_node.on_audit 落盤。兩個寫入者會讓 audit.jsonl 的順序變成
# 沒有人檢查的主張,並且讓那個檔案裡的缺口跟一筆被刪掉的紀錄長得一樣。
#
# 一個新 topic 讓四個閘變紅,而其中兩個紅是**閘自己的缺陷**:
#   - 一個子字串分不出發佈者與訂閱者(舊的卡片發佈者普查掃的是文字 "/memory/profile")。
#   - 一個只讀字面值的 parser 不是把普查**縮小**,是把它**弄崩**:
#     create_publisher(String, AUDIT_TOPIC, 10) 是這個 codebase 一直在用的形式,
#     而那個存在目的就是「注意到新的外流通道」的閘看不見一個這樣命名的通道。
#   兩個現在都去問 infra/ros_census.py —— topic 圖唯一的讀者,它解析常數,
#   而且對解不開的形式**拋異常**而不是安靜地縮小範圍。
#
# 還有一個沒能重現的數字:docs/design.md 的休眠百分比。這一輪把那道 find 走法寫下來
# (37,062 行 → 24.2%,先前三次讀數 26.6% / 25.8% / 25.3% 都沒有記下走法,而這一輪
# 沒能把 35,507 重現到 1,249 行以內),並且明說「從 25.3% 走到 24.2% 不可以讀成進展」
# —— 一部分是換了走法,一部分是新寫的 600 行測試。這個數字在這一輪自己又動過一次
# (36,995 → 37,062),因為修那個散文閘又加了 67 行;它是佈景,不是進度。要引用就引用接縫數。
#
# 逐位元推送慣例照舊:每個 blob 對 git hash-object 驗過,推完再逐位元讀回來比對。
