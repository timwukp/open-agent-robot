# R0a — 把「26.6% 的代碼庫只有 pytest 到得了」變成套件自己維護的事實。
#
# 這一輪加的不是功能,是一個**普查 + 登錄冊 + 雙向閘**。理由是一個量到的數字:
# 這個 repo 的五個承諾裡有四個只有 pytest 到得了,而在這之前**五個閘全部是綠的** ——
# 因為每一個閘問的都是「寫下來的東西彼此一致嗎」,沒有一個問「跑起來的那個行程
# 到得了這裡嗎」。`infra/wiring_census.py` 問後面那一句。
#
# 三個粒度,而每一個都是因為前一個被量到看不見一個真實接縫才存在的:
#   unreached (檔案)  沒有從 infra/run_ec2.sh 啟動的行程出發的呼叫路徑到得了它。
#   uncalled  (函式)  safety/guard.py 每一回合都被載入並被呼叫,所以任何檔案粒度的
#                     儀器永遠不會報它 —— 而那個活著的檔案裡有四個函式在機器人裡
#                     沒有呼叫者。這個儀器是被一個突變體的意外輸出逼出來的。
#   unpassed  (參數)  assemble 每一回合都跑,recall.py 的 909 行全部躲在
#                     `if recall is not None` 後面。整個子系統的休眠是**一個被省略
#                     的引數**,不是一個沒被 import 的檔案。
#
# 它產出的兩列 `defect` 是寫這個檔案的收益,不是副產品:
# agent/agent_node.py:265-269 用自己的 inline regex 把 safety/guard.py 的
# gesture_findings 與 spoken_text 實作了第二遍,而**活著的那一份沒有白名單檢查**。
# 今天沒有東西不安全地到得了致動器,只因為 body/body_node.py 做 GESTURES.get(name)
# 而把不認識的標籤靜默丟掉 —— 一個在下游的、意外的、從不進稽核的 containment,
# 而且那個檔案零測試。R1.6 修它,而在修好之前這件事是一列帶階段的資料,不是散文。
#
# 這份清單由**與 base tree 對帳**產生,不是憑記憶列的:base 是 main 的
# 6bb1327b5aa5(tree 052b68ffcfe1,145 個 blob,truncated=false),把工作樹每個檔案的
# `git hash-object` 跟它比一次,得到 8 個變更 + 8 個新增;扣掉刻意排除的 5 個之後
# 是 11 行,再加上推送機制自己的兩行,總共 13 個 blob。
#
# 這一輪是**從 main 開的**,不是疊在 #27 上:#26 與 #27 都已經在
# 2026-08-25T08:48Z 合併進 main,而 main 的樹裡確認有 tests/test_audit_schema.py
# (#27 的檔案)。「已合併」與「已落地」是兩件事,所以是查了樹才這樣寫的。
#
# 對出來的差集裡有五個檔案刻意不在清單上:daemon/miniaudio.h 與 daemon/oar-daemon
